# ImageMatch

**ImageMatch** is a desktop overlay image viewer designed for **stock image contributors** who need fast, manual similarity checks while browsing stock sites or working in any browser or application.

It lets you keep reference images floating above everything else, making visual comparison simple and focused.

## Why ImageMatch?

Stock platforms demand originality. ImageMatch helps contributors visually compare images **before uploading**, reducing the risk of rejection due to similarity.

No tab switching. No clutter. Just clean visual comparison.

---

## Features

- 🪟 **Always-on-top floating window**
- 🔍 **Zoom in and out** for detailed inspection (mouse wheel)
- 🖱 **Move and resize freely** anywhere on screen
- 🖼 **Load high-resolution images**
- 🗂 **Add and switch between multiple images** (arrow buttons)
- 🎯 Optimized for **manual visual similarity checking**

---

## Typical Use Case

1. Open a stock website (Shutterstock, Adobe Stock, iStock, etc.)
2. Launch **ImageMatch**
3. Load your image(s)
4. Visually compare composition, framing, and key elements
